# Introduction

Azur Web est la solution web de la suite logicielle Azur, conçue pour offrir un accès pratique et sécurisé aux fonctionnalités essentielles de gestion d'entreprise directement depuis un navigateur web.

## Présentation

Azur Web permet aux utilisateurs d'accéder aux données et fonctionnalités d'Azur de n'importe où, à tout moment, sans nécessiter d'installation sur poste de travail. Cette solution offre une interface moderne et intuitive adaptée aux besoins des utilisateurs mobiles et nomades.

## Fonctionnalités principales

- **Accès universel** : Connexion sécurisée depuis tout navigateur web
- **Interface responsive** : Adaptation automatique aux différentes tailles d'écran
- **Synchronisation en temps réel** : Données toujours à jour avec le système central
- **Sécurité renforcée** : Authentification sécurisée et gestion des droits d'accès

## Modules disponibles

Azur Web comprend plusieurs modules spécialisés répondant aux différents besoins métiers :

- **Delivery** : Gestion des livraisons et suivi des tournées

## Configuration requise

- Navigateur web moderne (Chrome, Firefox, Safari, Edge)
- Connexion Internet stable
- Compte utilisateur Azur valide
